# 声画工作台 · 品牌资产

场记板 Logo，2026-11-23 定稿。

## 文件

| 文件 | 用途 |
|---|---|
| `icon.svg` | 主图标（包图标 / 插件详情 / 市场展示），512 viewBox，深色底板 |
| `icon-line.svg` | 24×24 单色线稿，DSH 侧栏入口、工作台页头，`currentColor` |
| `icon-1024.png` … `icon-32.png` | 常用位图尺寸 |
| `preview.png` | 深浅底 + 小尺寸检查图 |

## 用法

- **彩色主图标**：只用于插件包图标、插件详情头图、市场/文档；不要塞进 16px 侧栏。
- **单色线稿**：侧栏 16px、页头 17px、空状态 24px；颜色跟 `currentColor`。
- 不在每个阶段页签、项目卡片、弹窗标题重复 Logo。

## 色板

- 墨褐 `#241b15`（底板）
- 纸白 `#f2e6cf`（板面）
- 暖金 `#d9a441`（场记板夹）
- 朱砂 `#c9442d`（声波重音，只占很小面积）
- 深棕 `#5b4428`（两侧声波）

图标为手写 SVG；`icon-*.png` 由无头 Chrome 按原尺寸透明底截图生成。
