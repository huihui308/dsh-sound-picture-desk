# 说书工作台 · DSH Story Desk

**中文** | [English](README.en.md)

把一个题材、一段历史、一本书，做成一条竖屏说书视频：写稿 → 定人物 → 配音 → 出图 → 合成，全部在一个面板里完成。

它是 [DeepSeek Harness](https://github.com/deepseek-ai)（DSH）的一个插件。不依赖剪辑软件，产出一条 1080×1920 的 mp4 和一版 SRT 字幕。

---

## 它是做什么的

传统做法是「写脚本 → 找素材 → 配音 → 剪辑」，一条视频要来回切五六个工具。这个插件把整条链路收进一个面板，并且**每一步都能停下来改**：

- 稿子写得不对味？直接在分段里改文字，改完再往下走。
- 想要人物长得一致？先给关键角色定一张标准像，后面每段分镜都照着它画。
- 声音不确定？九个音色点着听，选定再往下。
- 图不满意？逐张重出，不用整批重来。

**产出**：竖屏 mp4（1080×1920，可烧字幕）+ 同名 `.srt`。

---

## 环境要求

| 依赖 | 说明 |
|---|---|
| **DSH** | DeepSeek Harness 本体，插件跑在它的面板里 |
| **ffmpeg** | 合成成片必需（`ffmpeg`、`ffprobe` 在 PATH 里） |
| **写作模型** | 用 DSH 里已经接好的模型，不用另外配密钥 |
| **语音合成** | 支持小米 MiMo TTS（`chat/completions` 返回音频）；不配就只能选音色不能配音 |
| **图像生成** | 任意 OpenAI 兼容的 `/v1/images/generations`；或本机自建服务；MiniMax `image-01` 走它自己的原生接口 |

生图只要符合 OpenAI 兼容接口就行：阿里云 MaaS、MiniMax、OpenAI 官方、自建都行，插件里预置了这几家的地址。

MiniMax 有两条通道，插件按模型名自动分流：`image-01` / `image-01-live` 走原生 `POST /v1/image_generation`（固定 ¥0.025/张，慢一些），`MiniMax-H3-Image` 系列走 OpenAI 兼容入口（按 token 计费，1024×1792 约 ¥0.25/张但只需几秒）。选服务商时下拉里两条都列着。

## 安装

### 1. 拿到代码

```bash
git clone git@github.com:huihui308/dsh-story-desk.git
cd dsh-story-desk
```

### 2. 装进 profile

DSH 从 profile 的 `node_modules` 里加载插件。用 `dsh plugin` 安装本地目录（它会链接进去，而不是拷贝，所以改代码即时生效）：

```bash
# <profile> 是本机实际的 profile 名，默认 web
dsh plugin --profile web add /绝对路径/dsh-story-desk
```

也可以手动软链接：

```bash
ln -s "$(pwd)" ~/.dsh/profiles/web/node_modules/dsh-story-desk
```

### 3. 启用

重启 `dsh web`，进「Plugins」页面找到 **dsh-story-desk** 打开开关。

侧栏出现「说书工作台」即为成功。没出现就刷新页面。

### 4. 配一次通道

进插件后点右上角齿轮 →「生成图片」「生成声音」两个页签，各填一次地址和密钥：

设置分三个页签：**生成图片** / **生成声音** / **通用**。

- 服务商下拉里选一家（阿里云 MaaS / MiniMax / OpenAI / 小米 MiMo…），地址和模型会自动填好，也可以手动改。
- 「通用」页放回收站保留天数，以及新项目的默认开关（字幕压进画面、默认推近运镜）。运镜方向、调色、转场、片头这些逐个项目调，在「成片」页。
- 生成声音必须填密钥，否则无法配音。
- 生图如果走本机服务（免密钥），地址填到 `/v1` 为止。

## 项目管理

左侧列表放所有项目，鼠标移上去每一行右边浮出一个小叉：

- 点小叉 → 确认 → 项目移进**回收站**（不是直接删，稿子图和成片都留着）
- 回收站入口在列表底部，带数量角标；里面可以**还原**、**彻底删除**、**清空**
- 保留天数默认 **7 天**，在设置 →「通用」里改（1–365）。到期自动连同项目目录一起删掉

任务跑起来以后，进度条右边会出现**停止**按钮。点下去 ffmpeg 会被直接杀掉，1 秒内结束，不会卡在半路；停止后可以立刻重新生成。

## 快速开始

面板分成六个页签，从上到下走一遍即可。每一步都会在页签上显示进度（`✓` 完成 / `●` 当前）。

### ① 选题

填**题材**（例：玄武门之变 / 安史之乱 / 《万历十五年》），设**目标时长**和**每段多长**，然后点「生成稿件」。

- 有现成的资料就贴进「原始材料」，稿子会照着材料写，不照抄原句。
- 有中意的同类视频就粘进「参考视频」，写稿时会学它的选题角度和节奏。
- 写稿用的模型可以在这里换（默认跟随 DSH 当前模型）。

> 写一期 3 段稿子大约 1–3 分钟，取决于模型。推理型模型会先推演很久，界面上会显示「模型在推演（已想 N 字）」。

### ② 说书稿

按段显示旁白和画面描述，**直接改，离开输入框就保存**。确认稿子没问题再往下。

改动文字后，该段的配音和画面会失效，需要重新生成。

### ③ 参考图（可选，但推荐）

点「提取人物和场景」，模型会从稿子里挑出**真正反复出现**的角色与主场景，给出可以直接画图的形象描述。

- 每个条目单独画，一张张来；不满意就在输入框写「太年轻」「甲胄太亮」，点「按这条重画」——改动会累积。
- 满意就点「用这张定稿」。定稿的形象描述会拼进之后每一段分镜。

> 注意：当前的一致性在**文字层**——传给画图模型的是描述文字，不是那张图。做到「图像层」需要图片通道支持以图生图。

### ④ 旁白

九个音色按推荐排好（白桦带头，男声在前）。**点任意一行就现场合成约 15 秒样本并播放**，同时设为当前音色。

这里只定音色，不批量配音——整片配音放到最后一步一起做。

### ⑤ 分镜图

选**画面风格**（电影写实 / 国画工笔 / 连环画 / 水墨写意 / 暗调悬疑）和**画面比例**，点「出图」。

- 点「看 5 种」可以先用同一段文字把五种风格各画一张，挑一张再批量出。
- 每段可以单独「重出图」。点图能看大图，滚轮缩放。

### ⑥ 成片

点「**配音并合成**」：还缺的音会先补齐，然后逐镜头合成、拼接、压字幕，一次走完。

**特效**（合成时生效，改完重新合成即可）：

| 项 | 可选 | 说明 |
|---|---|---|
| 运镜 | 缓慢推近 / 缓慢拉远 / 固定不动 | 靠 zoompan 实现，先放大 2 倍再推，画面不抖 |
| 调色 | 原色 / 暖调 / 冷调 / 胶片 | ffmpeg colorbalance + eq；胶片档带暗角 |
| 转场 | 硬切 / 淡入淡出 / 经过黑场 / 溶解 / 向左擦除 / 圆形展开 | 用 xfade + acrossfade；开了就要逐段重编码 |
| 片头 | 不加 / 标题卡 | 用 HyperFrames 把 HTML 渲染成 3 秒标题卡，金色标题 + 分隔线 + 副标题 |

**渲染会优先用硬件编码器**：Mac 的 VideoToolbox、NVIDIA 的 NVENC、Intel QSV、AMD AMF，探测到就用，没有才回退 CPU。成片页底部会显示当前用的是哪个。

实测同一段 10 秒素材：CPU 35.4 秒 → NVENC 3.97 秒；一条 2 分钟的片子从 640 秒降到约 100 秒。

想强制用 CPU 就设环境变量 `STORY_DESK_ENCODER=cpu`。

成片出来后可以在页面上预览，也可以「导出」到指定目录（留空则导到 `~/Downloads`），文件名用项目标题。

## 数据存在哪

```
$DSH_HOME/story-desk/
├── state.json              所有项目、稿件、设置
├── secrets.json            通道密钥（0600）
└── projects/<id>/
    ├── audio/              每段旁白 mp3
    ├── anchors/            参考图候选与定稿
    ├── images/             每段分镜图
    ├── renders/            成片 mp4 / srt / ass
    ├── samples/            音色试听样本
    └── work/               合成中间文件
```

`$DSH_HOME` 默认是 `~/.dsh`。稿件存在 `state.json` 的 `items[].segments[]` 里，没有单独的稿子文件。

## 常见问题

**写稿报「没有返回正文，输出被长度上限截断」**
这个模型把 token 预算全用在推演上了。换成 DeepSeek-V4-Pro（约 3 分钟）这类直接的模型。glm-5.3、mimo-flash 这类会长时间推演的模型不适合写稿。

**出图报 503 / ComfyUI 不可达**
本机生图模型没启动。到 Gen Studio 控制台启动 Qwen-Image，或者在设置里换成平台通道。

**配音没声音 / 报密钥错误**
设置 →「生成声音」里填一次密钥。密钥存在 `secrets.json`，不进版本库。

**写稿很慢，是不是卡了**
看进度文案：显示「模型在推演（已想 N 字）」说明它在思考，字数在涨就没卡。真要卡住，20 分钟会自动超时。

## 开发

```
index.js           入口，把 host 导出
client.js          面板界面（手写单文件 bundle，用 DSH 注入的 react）
src/host.js        服务端路由、任务编排
src/script.js      写稿 prompt 与解析
src/tts.js         音色表与语音合成
src/images.js      生图通道与报错翻译
src/render.js      ffmpeg 合成（推近、拼接、字幕）
src/store.js       数据落盘、默认设置
src/jobs.js        后台任务、进度、超时
src/llm.js         调模型、流式进度、空输出兜底
docs/DETAIL.md     实现细节
```

改完代码要重新加载插件：「Plugins」页面把 **dsh-story-desk** 关掉再打开，然后刷新页面。

没有构建步骤——源码即部署。命令行里 `dsh plugin --profile web <pnpm 参数>` 只用来装包，没有单独的启停子命令。
