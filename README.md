# 说书工作台

把一个题材或一本书做成竖屏说书视频。面板里走六步：**选题 → 说书稿 → 旁白 → 参考图 → 分镜图 → 成片**。

## 怎么用

1. 侧栏点「说书工作台」，或在中央面板里选它。
2. 点「＋」新建：填一个题材（例：九子夺嫡）。有现成材料就展开贴上，稿子会照着材料写。
3. 点「写稿」：模型按说书人的口吻写成一段段旁白，每段配一个画面描述。
4. 点「配音」：每段合成一段 mp3，用 MiMo TTS。
5. 点「出图」：每段按画面描述生成一张 9:16 竖图，默认走本机 Qwen-Image（免费）。
6. 点「合成成片」：ffmpeg 把每段拼成镜头再接成整片，同时落一份 SRT。

任一段都能单独「重配音」「重出图」；直接改文字或画面描述，离开输入框就保存，改过的段落会提示重新配音。

## 三条通道

| 通道 | 默认 | 说明 |
|---|---|---|
| 文案 | 跟随当前默认模型 | 用 DSH 里已接的模型，不另外配密钥 |
| 旁白 | 小米 MiMo TTS `mimo-v2.5-tts` | token-plan 端点；密钥只存在 `$DSH_HOME/story-desk/secrets.json`（0600） |
| 画面 | 本机 Qwen-Image `127.0.0.1:30021` | 免费；也可切到 OpenAI 兼容的平台接口 |

## 设置里的通道配置

右上角齿轮打开设置，分成两个页签：**生成图片**、**生成声音**，点一个只显示对应那一块。每块第一项是「服务商」下拉：

- 选中某家（生成图片：本机 Qwen-Image / 阿里云 MaaS / MiniMax / OpenAI 兼容；生成声音：小米 MiMo / 小米 MiMo 公众版），地址和模型自动填好，**仍然可以改**。
- 选「自定义（自己填地址）」，就自己填地址和模型；一项都不填也无所谓，会存下你写的内容。
- 服务商同时决定了接口形态：本机走 `/generate` 且免密钥，其余走 OpenAI 兼容的 `/images/generations`。所以没有单独的「协议」选项。
- 改了地址但没选下拉时，下拉会显示成「自定义」——因为地址已经不是预设那家的了。
- **检测连接**是真打一次请求：本机探 `/health`，平台探 `/models` 验地址与密钥，声音通道实际合成一句「测试。」。结论会区分——401 说明地址通了但 key 不对，连不上说明地址或网络不对，404 说明路径填错。

首次启动会从 `~/.story-video/secrets.env` 导入一次已有密钥，省得重填。密钥只写不读，界面只知道「配过没有」。

## 五个阶段页

主页面按阶段分成五个页签，点一个只显示这一页：

| 页 | 这一页管什么 | 配置放在这 |
|---|---|---|
| ① 选题 | 题材、目标时长、**参考视频**（一行一个链接，会抓标题）、**写稿用哪个模型**、原始材料 | — |
| ② 说书稿 | 分段旁白与画面描述，每段配一张图，点图看大图 | 每段时长 |
| ③ 旁白 | 音色试听、配音、逐段重配 | 音色 |
| ④ 参考图 | 从稿件抽人物场景、一张张画与改、定稿 | —（可选步骤） |
| ⑤ 分镜图 | 风格试画、出图、逐张重出 | 画面风格、画面比例 |
| ⑥ 成片 | 合成、播放、导出 | 推近、烧字幕 |

- 打开项目自动落在第一个没做完的页；页签上 `✓` 是完成、`●` 是当前。
- 前置没做时给提示和跳转按钮，页签永远可点。
- 操作完不自动跳页。
- 配置按项目存，不是全局——不同的书适合不同的画面风格。
- **写稿会顺带配图**：稿子一落地就把每段的分镜图出好，所以「② 说书稿」打开就是一段一张图。配图失败不会让稿子白写，只会把该段标成待重出。

## 参考图（人物与场景一致性）

第 ④ 页。同一部片子里李世民在三段中得是同一个人，所以先把关键形象定成标准像：

1. 「从稿件提取人物和场景」——模型读完旁白，列出**真正反复出现**的角色与主场景（路人、群众不列），给出可直接画图的形象描述（年龄、体型、服饰形制、发型、随身物件）。
2. 每个条目单独画，一张张来；不满意就在输入框写「太年轻」「甲胄太亮」，点「按这条重画」，改动会累积进描述。
3. 满意就「用这张定稿」。
4. 定稿的形象描述会拼进之后每一段分镜的 prompt。

**当前的一致性级别是「文字层」**：定稿图给你看和确认，真正传给画图模型的是它的描述文字，不是那张图。做到「图像层」需要图片通道支持以图生图——本机服务的 `/generate` 接受 multipart 上传参考图，OpenAI 兼容的 `/images/generations` 不接受；等本机服务常驻后可以接上。

## 右侧助手

面板右侧常驻一条助手栏，可以直接说话改稿，模型跟随 DSH 当前默认模型（不单独配）。

- 它知道当前项目的每一段：旁白、画面描述、有没有配音。
- 说「第三段太长」「开头不够抓人」「第二段画面换成夜里的宫门」，它会只改你点到的那几段。
- 改完立刻落盘：那几段标成未配音（文字变了，旧音频对不上），画面描述变了的标成未出图，成片自动作废，阶段往回退。
- 没让你改的段落一律原样不动。

收起后是一条 40px 的竖条，点开就回来。

## 产物在哪

```
$DSH_HOME/story-desk/
  state.json              项目与分段状态
  secrets.json            密钥（0600，不进 state）
  projects/<id>/
    audio/                每段旁白 mp3
    images/               每段分镜图 png
    renders/video.mp4           成片
    renders/video.srt           字幕（SRT，给剪辑软件）
    renders/video.ass           字幕（ASS，带画布尺寸，用于压画面）
    renders/video-subtitled.mp4 压了字幕的成片（开关打开时）
```

## 限制

- 一次只跑一个任务，同一项目不会并发写。
- 画面比例在项目内可以改，但改完已出的图不会自动重出（要手动「全部重出图」）。
- 成片是「静图 + 慢推 + 旁白」的联播形态，不做口型、不做多轨配乐。
- 字幕按句拆条（一句话一条），时间按字数占该段音频的比例分配；没有逐字时间戳，语速突变的那一句会略微偏。
- 字幕烧录用 ASS（文件头写死 PlayRes 1080×1920），依赖系统有中文字体（本机为文泉驿正黑）；没有字体时不烧，只出 SRT。
